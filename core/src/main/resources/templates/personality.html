Learn from media

There is no per-file 10 MB limit; the total upload request is limited to 1 GB. Choose a file or image link, not both. If you leave the image comment blank, Minerva will describe the image first. HTML scripts are not run; only eligible referenced media is fetched.

Learn from an article

Minerva reads public HTML articles only. Article text is treated as untrusted content; your comment guides the preference update.

Upload a ZIP of HTML pages and images

Up to 50 HTML and image files, including files in nested folders. ZIPs are limited to 100 MB compressed, 20 MB per file and 100 MB uncompressed in total. Files are processed independently; failures are listed by filename. Public images referenced by HTML are fetched as usual; local references are not resolved.

Upload multiple images

A maximum of 50 files can be uploaded in one go. Each image is processed independently; successful analyses are saved even if another image fails.

Upload multiple HTML files

A maximum of 50 files can be uploaded in one go. Each file is processed independently through the same HTML workflow. Up to 50 referenced media items per page are analysed; successful files are saved even if another file fails, and failures are listed by filename.
